# 🏮 成语接龙 · 雅趣国风典藏版

> 一款基于纯原生 HTML5 / CSS3 / ES6 构建的单文件国风成语接龙小游戏。  
> **零外部依赖 · 零构建工具 · 离线秒开 · 内置 30,000+ 纯正成语词库**。

---

## ✨ 核心特性

- 📚 **30,000+ 纯正海量词库**：
  - 深度融合《新华成语大词典》正统成语与清华大学开放中文词库（THUOCL 高频成语）；
  - 精选补充常用现代熟语（`前程似锦`、`心想事成`、`风生水起`、`奇思妙想`、`未来可期`、`大吉大利` 等）；
  - 经过严格词性清洗，杜绝现代政治口号或普通名词杂质。
- ⚡ **双重 $O(1)$ 哈希索引**：
  - 3,100+ 首字汉字哈希表 + 390+ 首字拼音哈希表；
  - 3 万条海量词库下，首尾接龙检索耗时 `< 0.1ms`。
- 🎵 **Web Audio 原生五声音阶合成音效**：
  - 采用宫、商、角、徵、羽（C4-D4-E4-G4-A4）算法实时合成，无需加载外部音频文件；
  - 连击（Combo）阶梯式升调，伴随沉稳落子音与庆典乐音，支持一键静音（🔊/🔇）。
- 🗣 **普通话真人语音朗读（TTS）**：
  - 基于 Web Speech API，成语卡片一键点击标准普通话朗读发音。
- 🏆 **科举功名·11 阶文官晋升系统**：
  - `布衣` → `童生` → `秀才` → `举人` → `贡士` → `进士` → `探花` → `榜眼` → `状元` → `翰林学士` → `文曲星君`；
  - 实时印章展示，晋升触发喜报与五音礼乐。
- 🎮 **三大经典对战模式**：
  - 🌸 **悠闲漫吟**：经典从容无时限模式；
  - ⚡ **金榜速对**：20 秒倒计时紧张挑战，超时断龙；
  - 🎯 **严选同字**：硬核同字接龙（禁止同音替代）。
- 📜 **状元及第·古风卷轴结算单**：
  - 终局弹出水墨卷轴战报，总结功名、得分、连击与诗意评语，支持一键复制战报文案。
- 📱 **深度移动端适配**：
  - `VisualViewport` 软键盘动态避让，输入栏自动吸附在手机键盘上方；
  - 原生马达触感震动反馈（Haptics）；
  - 锁定 `overscroll-behavior: none` 防下拉刷新误触，锁定 16px 字体防 iOS 强制缩放；
  - 弹性流底端布局，彻底杜绝输入栏遮挡最新卡片。
- 🌸 **唯美落樱微动效**：
  - 原生轻量 Canvas 绘制花瓣飘拂，支持一键开关。

## 🎮 玩法规则

1. **接龙规则**：
   - **同字接龙**：输入成语首字与上一成语尾字汉字完全一致。
   - **同音接龙**：首字与尾字同音即可（声母韵母一致，不限声调）。
   - **严选模式**：只能同字接龙。
   - **去重防刷**：本局已出现的成语不可重复使用。
2. **人机对弈**：
   - 玩家出招后，电脑自动接招（模拟 500ms 思考动效，优先出高频知名成语）；
   - 若电脑无词可接，自动判定玩家大胜并奖励 50 分！
3. **求助机制**：
   - 遇到困难时可点击底部【💡 提示求助】查看候选推荐，平时界面保持纯粹，全凭脑力思考。

## 🚀 快速开始

### 本地运行
无需安装任何环境，克隆或下载后直接在浏览器打开：
```bash
git clone https://github.com/iskuggy/idiom-game.git
cd idiom-game
open index.html
```

### GitHub Pages 在线畅玩
在 GitHub 仓库中开启 Pages：
1. 进入仓库 **Settings** -> **Pages**；
2. **Branch** 选择 `main`，目录选择 `/ (root)`，点击 **Save**；
3. 即可通过 `https://iskuggy.github.io/idiom-game/` 直接在线免安装畅玩！
